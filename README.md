# FrogID — Frog Call Species Classifier

## a. Problem statement

Frog calls can be represented by mel-frequency cepstral coefficients (MFCCs). This project compares five supervised classifiers on 22 MFCC measurements to predict the frog species associated with a call syllable. The comparison uses an independent held-out set grouped by recording, so syllables from the same specimen do not occur in both training and test data.

## b. Dataset description

The dataset is **Anuran Calls (MFCCs)** from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/406/anura). It contains 7,195 syllable instances, 22 real-valued MFCC features, and labels for 10 species. The source also includes family, genus, and recording ID fields. `Species` is the prediction target; `Family`, `Genus`, and `RecordID` are excluded from model inputs to avoid target leakage and recording overlap.

The source CSV is included in `data/Frogs_MFCCs.csv`. UCI lists the dataset under the **CC BY 4.0** license. Attribution: Colonna, J., Nakamura, E., Cristo, M., & Gordo, M. (2015). *Anuran Calls (MFCCs)*. UCI Machine Learning Repository. [doi:10.24432/C5CC9H](https://doi.org/10.24432/C5CC9H).

### Model observations

The observations below describe this fixed, group-held-out test run. Macro scores weight each species equally, while accuracy weights each syllable equally.

| ML Model | Observation about this test result |
|---|---|
| Logistic Regression | Its AUC is strong (0.9788), but its macro recall (0.7126) and macro F1 (0.6717) are lower. It ranks species well overall, but its predicted classes are less balanced across species. |
| Decision Tree | It has the lowest AUC (0.8181), macro recall (0.6106), and macro F1 (0.6079) in this comparison, indicating the weakest balanced performance on this test set. |
| KNN | It leads in accuracy (0.9253), macro precision (0.8446), macro recall (0.8515), macro F1 (0.8157), and MCC (0.8971). It is the strongest overall classifier by most reported metrics in this run. |
| Naive Bayes | It has the lowest accuracy (0.8512), while its AUC remains relatively high (0.9567). Its macro recall (0.7445) exceeds its macro precision (0.7167), so its coverage across species is better than the precision of its predictions. |
| Support Vector Machine | It achieves the highest AUC (0.9905), with strong macro recall (0.8366) and macro F1 (0.7928). KNN scores higher on accuracy, macro F1, and MCC, so the preferred model depends on whether ranking quality or final class decisions matter more. |
| Overall winner for this dataset | KNN is the overall winner if the priority is accuracy and balanced classification performance: it leads on five of the six metrics. SVM is the winner on AUC alone. |

**Interpretation caveat:** the group-held-out test set contains only three `OsteocephalusOophagus` syllables. Its per-species metrics are therefore highly uncertain, and the macro averages include that small class sample.

## Evaluation design

- A deterministic species-stratified holdout assigns whole `RecordID` groups to test; all species remain represented in both partitions.
- Species frequencies are highly uneven. In this group-safe test split, `OsteocephalusOophagus` has only three syllables; interpret per-species scores and macro metrics with that small support in mind.
- Model inputs contain only the 22 MFCC measurements. `RecordID`, `Family`, and `Genus` are metadata/related labels, not predictors.
- Standard scaling is used in the Logistic Regression, KNN, and SVM pipelines. The tree and Gaussian Naive Bayes use the original normalized MFCC values.
- The app computes accuracy, macro one-vs-rest AUC, macro precision, macro recall, macro F1, and MCC for each model on the uploaded test data.
