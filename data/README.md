# Dataset source and attribution

`Frogs_MFCCs.csv` is the Anuran Calls (MFCCs) dataset from the UCI Machine Learning Repository.

- Dataset page: https://archive.ics.uci.edu/dataset/406/anura
- Citation: Colonna, J., Nakamura, E., Cristo, M., & Gordo, M. (2015). *Anuran Calls (MFCCs)*. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC9H
- License: Creative Commons Attribution 4.0 International (CC BY 4.0), as listed by UCI.
